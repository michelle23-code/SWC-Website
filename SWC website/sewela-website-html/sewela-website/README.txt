SEWELA Consultants website — plain HTML, CSS and JavaScript
============================================================

FILES
  index.html      Home page
  services.html   Services page (CIPC, SARS, Other)
  about.html      About page
  contact.html    Contact page
  styles.css      All colours, fonts and layout (black & white theme)
  script.js       Mobile menu, highlights the current page, footer year
  images/         Office photo and SC logo
  favicon.ico     Browser tab icon

HOW TO VIEW
  Unzip the folder and double-click index.html. It opens in your browser.

HOW TO EDIT
  Open any .html file in a text editor (Notepad, VS Code) and change the words.
  Your phone number, email and address appear on every page in the header/footer,
  so use "Find and replace" in all files when they change.
  Colours are at the top of styles.css (--black, --white, etc.).

HOW TO PUT IT ONLINE (free options)
  - Netlify Drop: go to app.netlify.com/drop and drag this folder in.
  - GitHub Pages, or upload all files to your web host's public_html folder.
